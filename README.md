# 2027 DSE 倒數計時器 🎓

A beautiful countdown timer for the 2027 Hong Kong Diploma of Secondary Education (DSE) examinations.

## 功能特色 Features

- ⏰ **即時倒數** - 顯示距離考試嘅日、時、分、秒
- 📚 **2027 考期資訊** - 已將 2027 相關考期資訊整合在此網站，方便查看倒數與科目安排
- 💾 **自動保存** - 使用 localStorage 保存你選擇嘅科目
- 📱 **響應式設計** - 手機、平板、電腦都適用
- ✨ **精美動畫** - 流暢嘅 CSS 動畫效果
- 💪 **鼓勵訊息** - 廣東話勵志金句不斷更新
- 🎯 **網格展示** - 清晰顯示所有考試科目同時間

## 使用方法 Usage

1. 打開網頁：[Live Demo](https://novameowtech.github.io/dse-countdown/)
2. 點擊科目按鈕選擇/取消你要考嘅科目
3. 你嘅選擇會自動保存，下次打開網頁會記住

## 技術細節 Technical Details

- 純 HTML + CSS + JavaScript，無需任何框架
- 使用 localStorage API 儲存用戶設定
- CSS Grid 實現響應式網格佈局
- 每秒更新倒數計時
- 支援 GitHub Pages 部署

## 部署到 GitHub Pages

1. 將代碼推送到 GitHub repository
2. 喺 Settings > Pages 啟用 GitHub Pages
3. 選擇 main 或 master branch
4. 等幾分鐘就可以訪問你嘅倒數計時器！
